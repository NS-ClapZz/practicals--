# Тестирование и верификация решения

Документ описывает результаты автоматического и ручного тестирования компонентов системы ShopSystem.

## Автоматические тесты и сборка

Запуск тестов и сборки решения выполняется командами:

```powershell
dotnet test .\ShopSystem.sln
dotnet build .\ShopSystem.sln
```

- **Статус сборки:** 0 ошибок, 0 предупреждений.
- **Статус тестов:** пройдены все 4 модульных теста проекта `ShopSystem.Application.Tests` (проверка валидации создания заказов и добавления товаров в каталог).

## Проверка REST API

Основные сценарии проверены через HTTP-запросы к запущенному экземпляру API с тестовой базой данных SQLite:

| Сценарий | Код ответа | Описание |
|---|---|---|
| Регистрация и авторизация | 201 / 200 | Успешное создание учетной записи и установка сессионных cookie |
| Гостевой доступ к избранному | 401 | Неавторизованный запрос корректно отклоняется |
| Управление избранным | 204 / 200 / 204 | Добавление товара, просмотр списка и удаление из избранного |
| Публикация отзыва | 201 / 409 | Добавление оценки и текста отзыва; защита от повторной отправки |
| Расчет рейтинга | 200 | Корректный пересчет среднего рейтинга товара на основе отзывов |
| Валидация входных данных | 400 | Отклонение некорректных значений рейтинга (< 1 или > 5) |
| Авторизация администратора | 200 | Доступ к списку отзывов для модерации |
| Разграничение прав | 403 | Запрет доступа обычного покупателя к эндпоинтам модерации |
| Модерация отзывов | 204 | Удаление некорректного отзыва администратором и пересчет рейтинга |
