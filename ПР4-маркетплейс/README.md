# Практическая работа №4 — Интернет-магазин (ShopSystem)

Клиент-серверная система интернет-магазина на платформе .NET 8. Включает серверную часть (REST API на ASP.NET Core с базой данных SQLite) и клиентскую часть (настольное приложение на WPF).

## Возможности системы

### Каталог и корзина
- Просмотр каталога товаров, фильтрация по категориям и диапазону цен, поиск по названию.
- Добавление товаров в корзину с изменением количества и удалением позиций.
- Возможность быстрой покупки одного товара.
- Добавление товаров в «Избранное» и перенос их в корзину.

### Оформление заказа и доставка
- Расчет способа получения в зависимости от суммы заказа:
  - адресная доставка доступна для заказов от 600 ₽;
  - для заказов на меньшую сумму доступен самовывоз из пунктов выдачи заказов (ПВЗ).
- История заказов покупателя с деталями каждого заказа (название товара, цена на момент покупки, количество и итоговая сумма).

### Отзывы и рейтинг
- Публикация отзывов и оценок (от 1 до 5 звезд) авторизованными пользователями.
- Расчет и отображение среднего рейтинга товара в каталоге.
- Просмотр всех отзывов о товаре.

### Панель администратора
- Управление номенклатурой товаров (создание, редактирование, управление остатками и доступностью).
- Управление категориями товаров и пунктами выдачи.
- Смена статусов заказов (`New`, `Processing`, `Delivered`, `Cancelled`).
- Модерация и удаление отзывов.

## Требования

- ОС Windows (для запуска графического интерфейса WPF);
- .NET 8 SDK или новее.

## Запуск приложения

Для полноценной работы системы требуется запустить API-сервер и WPF-клиент.

### 1. Запуск серверной части (API)

Из корневой папки `ПР4-маркетплейс`:

```powershell
dotnet run --project .\src\ShopSystem.Api -- --urls http://127.0.0.1:5077
```

При первом запуске автоматически формируется файл базы данных SQLite `shop.db`, заполняются тестовые категории, товары и пункты выдачи.

> Для создания учетной записи администратора можно задать переменную окружения:
> `$env:SHOP_ADMIN_PASSWORD="YourPassword"` перед запуском API. По умолчанию имя администратора: `admin`.

### 2. Запуск клиентской части (WPF)

В отдельном терминале запустите клиент:

```powershell
dotnet run --project .\src\ShopSystem.Desktop
```

Клиент автоматически подключается к API по адресу `http://127.0.0.1:5077`.

## Сборка и тестирование

Сборка всех проектов решения и запуск автоматических тестов:

```powershell
dotnet restore .\ShopSystem.sln
dotnet build .\ShopSystem.sln
dotnet test .\ShopSystem.sln
```
