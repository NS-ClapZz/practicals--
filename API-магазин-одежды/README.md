# Практические работы № 12–13: REST API магазина одежды

Учебный проект REST API для интернет-магазина одежды, разработанный на платформе ASP.NET Core (.NET 8) с использованием Entity Framework Core и базы данных SQLite.

## Возможности

- **Каталог товаров:** получение списка одежды, фильтрация и регистронезависимый поиск по названию.
- **Размеры и остатки:** учет доступности каждого товара в разрезе размеров (S, M, L и числовые размеры) с автоматическим списанием при заказе.
- **Аутентификация и авторизация:**
  - Регистрация и вход пользователей с безопасным хешированием паролей (`IPasswordHasher`).
  - Разделение прав доступа по ролям: `Customer` (покупатель) и `Manager` (менеджер магазина).
  - Аутентификация на основе cookie-сессий (`ClothesApi.Session`).
- **Заказы:** оформление заказов авторизованными пользователями с фиксацией цены, названия и размера на момент покупки, а также просмотр истории заказов.
- **Панель менеджера:**
  - Управление статусами заказов (`New`, `Processing`, `Completed`, `Cancelled`).
  - Изменение складских остатков по размерам.
  - Управление доступностью товаров в каталоге.

## Требования

- .NET 8 SDK или новее;
- Postman (для тестирования API эндпоинтов).

## Запуск приложения

1. Перейдите в папку проекта:
   ```bash
   cd ClothesApi
   ```

2. Запустите сервис:
   ```bash
   dotnet run
   ```

По умолчанию API запускается на `http://localhost:5000` (или `http://localhost:5077` в зависимости от конфигурации). При первом старте автоматически создается файл базы данных `clothes.db` и инициализируются начальные категории и товары.

### Переменные окружения (опционально)

- `CLOTHES_DB` — путь к файлу SQLite (по умолчанию: `clothes.db`).
- `CLOTHES_MANAGER_LOGIN` — логин учетной записи менеджера (по умолчанию: `manager`).
- `CLOTHES_MANAGER_PASSWORD` — пароль учетной записи менеджера (при передаче создается при первом старте).

## Тестирование через Postman

Для проверки работы API подготовлены коллекция `ClothesApi.postman_collection.json` и файл окружения `ClothesApi.postman_environment.json`.

1. Импортируйте коллекцию и окружение в Postman.
2. Убедитесь, что переменная `baseUrl` указывает на запущенный сервер (например, `http://localhost:5000`).
3. Запустите коллекцию через **Postman Collection Runner**.

Коллекция включает 13 запросов и 22 автоматические проверки (проверка статусов HTTP, структуры JSON, валидации полей, создания заказов и ролевого доступа). Скриншоты успешного прохождения тестов и деталей выполнения сохранены в папке `docs/screenshots/`.
