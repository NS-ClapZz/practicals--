# Практические работы по курсу ИСРПО

Репозиторий содержит учебные проекты практических работ по дисциплине «Инструментальные средства разработки программного обеспечения».

## Состав репозитория

В репозитории представлены два основных проекта:

1. **[`API-магазин-одежды`](API-магазин-одежды/)** (Практические работы № 12–13)
   - Серверная часть REST API магазина одежды на ASP.NET Core (.NET 8).
   - База данных SQLite с Entity Framework Core.
   - Механизм авторизации на сессионных cookie с ролевым доступом (`Customer`, `Manager`).
   - Учет складских остатков по размерам, оформление заказов и управление статусами.
   - Готовая коллекция и окружение Postman с набором автоматических тестов (13 запросов, 22 проверки).

2. **[`ПР4-маркетплейс`](ПР4-маркетплейс/)** (Практическая работа № 4)
   - Полнофункциональная система интернет-магазина (ShopSystem).
   - Многослойная архитектура:
     - `ShopSystem.Core` — доменная модель;
     - `ShopSystem.Application` — прикладные сервисы и интерфейсы;
     - `ShopSystem.Infrastructure` — хранилище данных;
     - `ShopSystem.Api` — REST API сервер с SQLite;
     - `ShopSystem.Desktop` — графический интерфейс на WPF;
     - `ShopSystem.ConsoleApp` — консольная демонстрационная версия.
   - Функционал: каталог товаров с фильтрацией и поиском, корзина, оформление заказов (доставка от 600 ₽ или самовывоз из ПВЗ), система избранного, отзывы с рейтингом и модерация.
   - Набор модульных тестов на xUnit (`ShopSystem.Application.Tests`).

## Системные требования

- **ОС:** Windows 10/11 (требуется для сборки и запуска WPF-клиента);
- **SDK:** .NET 8 SDK или новее.

## Быстрый старт и сборка

### Сборка и тестирование решения ShopSystem (ПР4)

```powershell
cd .\ПР4-маркетплейс
dotnet restore .\ShopSystem.sln
dotnet build .\ShopSystem.sln
dotnet test .\ShopSystem.sln
```

### Запуск API магазина одежды (ПР 12–13)

```powershell
cd .\API-магазин-одежды\ClothesApi
dotnet run
```
