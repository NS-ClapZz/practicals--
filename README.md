# Практическая работа №3 по ИСРПО 12–13

Я реализовал REST API магазина одежды на ASP.NET Core 8 с Entity Framework Core и SQLite.

В проекте я подготовил:

- каталог одежды и поиск по названию;
- регистрацию и вход с хешированием паролей;
- ролевой доступ покупателя и менеджера;
- оформление и просмотр заказов с учётом размеров и остатков;
- менеджерские операции с заказами, остатками и доступностью товаров;
- коллекцию Postman с запросами и автоматическими проверками;
- файлы решений Visual Studio `.sln` и `.slnx`.

Исходный код проекта находится в папке [`API-магазин-одежды`](API-магазин-одежды/). Инструкции по запуску и проверке находятся в её README.
